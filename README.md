# Soontra MCP Server

The AI content workspace — search everything your company has ever recorded, right from Claude or ChatGPT.

Soontra indexes your company's video, audio, images and documents so every moment is searchable. Through this MCP server, Claude, ChatGPT, Cursor and VS Code search the same workspace the Soontra app searches.

## Connect

- Remote MCP server (Streamable HTTP): https://app.soontra.com/api/mcp
- Auth: OAuth 2.1 with dynamic client registration — when your client prompts, sign in with your Soontra account and approve access to your workspace.

## What you can do

- Search your whole media archive and land on the exact moment in a recording
- Pull files, folders, transcripts and documents
- Read YouTube, Instagram and TikTok analytics
- Create post drafts (drafts only — publishing happens in the Soontra app)
